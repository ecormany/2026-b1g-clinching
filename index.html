Road to Indy

Six teams can still reach the Big Ten Championship Game. The tree starts as one trunk and splits at each game that matters. A band's width shows how likely that path is, based on the betting lines. When a branch is decided, it ends with the title-game matchup.

Order games by

How to read it. Games run top to bottom, starting with the ones that decide the most. You can switch to kickoff order instead, which makes a bushier tree because the early games settle little. Each band is colored for the team that wins that game. If a game can't change the result within a branch, the band passes straight through that row. Tap a band or an end point to read that path, then lock in its results. Tap a team at the top to highlight every path that sends it to Indy. Option-click (Alt-click) a pick to watch the change in slow motion, a trick taken from the New York Times' 512 Paths to the White House.
